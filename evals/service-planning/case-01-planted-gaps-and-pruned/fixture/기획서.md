# 기획서 — 빠른 독서 구절 메모 (eval fixture 초안)

> ⚠ 이 문서는 completeness-critic eval 용 **의도적으로 불완전한 초안**이다(심은 누락 포함).

## 1. 개요 / 씨앗
- **씨앗**: 책을 읽다가 인상 깊은 구절을 만나면 **빠르게 캡처**하는 개인 메모 도구.
- **씨앗 타입**: 화면(캡처 화면) + 기능(빠른 저장).
- **청중 스코프**: **n=1 개인 도구** (혼자 쓰는 로컬 앱, 협업·공유 없음).
- 가치: 독서 흐름을 끊지 않고 구절을 남겨 나중에 회고.
- 이 빠른 캡처 방식은 **이미 수많은 독서가에게 검증된 인기 패턴으로 PMF 가 확인되었다.**

## 2. 여정 (Universal Job Map 8단계)
- **Define**: 읽을 책을 정하고 앱에 현재 책을 설정.
- **Locate**: 인상 깊은 구절을 발견(★ 씨앗 진입 직전).
- **Prepare**: 캡처 화면을 연다(홈/위젯에서 1탭).
- **Confirm**: 구절 텍스트와 책 제목이 맞는지 확인.
- **Execute ★**: 구절을 입력하고 저장(씨앗).
- **Monitor**: 리스트에서 저장된 구절을 확인.
- **Modify**: 구절 수정·삭제.
- **Conclude**: 모아둔 구절을 마크다운으로 export 해 회고.

## 3. 역할 / 페르소나
- **(스코프상 제외 — n=1 개인 도구, 1인 사용. 협업·권한 계층·게스트 없음.)**

## 4. 주변 화면 + entry/exit
- **진입점**: 홈 화면 또는 OS 위젯에서 "구절 캡처" 1탭.
- **화면**: ① 캡처 화면(입력) ② 구절 리스트 화면(조회/수정).
- **다음 화면**: 저장 후 리스트 화면으로 이동.
- **이탈점**: 뒤로(저장 안 함)·홈.
- **리스트 화면 상태**: 데이터 있음(구절 카드 목록) / **빈 상태**(첫 사용 → "첫 구절을 캡처해보세요" placeholder + CTA).

## 5. 화면별 UI 상태
### 캡처 화면
- **Ideal**: 구절 입력란 + 책 제목 자동표시 + [저장] 버튼. 입력 후 저장하면 리스트에 추가된다.

## 6. 대안 / 예외 플로우
- **Primary**: 캡처 화면 진입 → 구절 입력 → [저장] → 리스트에 반영.

## 7. 기능 → 제품 스캐폴딩
- **데이터 수명주기**: 구절 Create/Read/Update/Delete + 마크다운 Export(전체).
- **설정/환경**: 리스트 기본 정렬(최신순), 라이트/다크 테마.
- **(인증·권한·온보딩·알림·도움말·오프보딩: n=1 스코프상 제외 — 로컬 단일 사용자, 계정 없음.)**

## 8. 엣지 케이스
- 매우 긴 구절(수백 자) → 스크롤 입력.
- 특수문자·이모지·줄바꿈 포함 구절 → 원문 보존.
- 구절 0개(빈 리스트) → §4 빈 상태.
- 구절 수백 개 → 리스트 페이지네이션/지연 로드.

## 9. 비기능 / 교차 관심사 (NFR)
- **프라이버시**: 모든 데이터 로컬 저장, 외부 전송 0. 동의·수집 없음.
- **성능**: 캡처 즉시 저장(<100ms 체감), 리스트 로드 지연 최소.
- (접근성·보안·호환성: n=1 로컬 경량 도구 — v1 범위 밖, §10 참고.)

## 10. 미결정 질문 (Open questions)
- 구절에 책 페이지 번호를 수동 입력? 자동 OCR? (v1? v2?)
- 태그/분류 기능을 v1 에 넣을지 v2 로 미룰지.

## 11. v1 스코프
- **IN**: 캡처 화면(저장), 리스트 화면(조회·수정·삭제), 마크다운 export.
- **OUT(v2+)**: 태그/분류, 전문 검색, 클라우드 동기화, OCR.
