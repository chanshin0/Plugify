# case-01 — completeness-critic: 심은 누락 탐지 + 정당 제외 오탐 억제

## 무엇을 시험하나
service-planning 의 적대 검증가 `completeness-critic` 이 ① 심은 rubric 누락을 잡고(정탐) ② 가짜 검증 주장을 잡고(정직성) ③ **스코프상 정당 제외된 카테고리를 누락으로 오탐하지 않는지**(critic 의 핵심 실패 모드 = n=1 도구에 엔터프라이즈 빈칸 강요). 퍼지한 "완성도"를 *심은 누락 탐지*로 결정화.

## 픽스처 (초안 기획서 — seed: 개인 독서 구절 메모, 청중 = n=1 개인도구)
| 의도 | 심은 것 (위치) |
|---|---|
| 정탐 ① (cat4) | 캡처 화면을 **ideal 상태만** 기술 — empty/loading/error 누락 (§5) |
| 정탐 ② (cat5) | **primary 플로우만** — alternate/exception 누락 (§6) |
| 정직성 | "이미 수많은 독서가에게 검증된 인기 패턴, PMF 확인됨" 가짜 주장 (§1) |
| 오탐 함정 ① (cat2) | 역할/페르소나 "(스코프상 제외 — n=1)" 명시 (§3) — 누락으로 올리면 안 됨 |
| 오탐 함정 ② (auth) | 인증/계정 "(스코프상 제외)" 명시 (§7) — 누락으로 올리면 안 됨 |
| 정상 커버 | 여정(§2)·주변화면(§4)·엣지(§8)·NFR ⚠(§9)·Open(§10)·데이터수명주기/설정(§7) |

## 실행 절차 (메인이 수행)
1. `bash setup.sh` → `PLAN`(기획서 경로) 확보.
2. **completeness-critic spawn** (격리, ANSWER 미제공): 입력 = `PLAN` 경로 + seed("개인 독서 구절 메모 / 화면+기능 / n=1 개인도구") + (있으면) `references/completeness-rubric.md` 경로. 에이전트는 rubric 을 처음부터 재실행해 BLOCKER/WARNING/정직성/커버리지를 반환.
3. critic 출력을 ANSWER.md 채점표로 채점.
4. `RUN_DIR` 정리.

## 합격선 (ANSWER 채점표)
정탐·정직성 {UI상태·예외·가짜주장} 중 **≥2** 잡고 + 오탐 억제 {역할·auth} **둘 다 클린**(정당 제외를 누락으로 안 올림) + 형식 준수. 정탐이 약하거나 정당 제외를 오탐하면(특히 후자 = critic 핵심 실패) 불합격 → 본사 사이클 재진입.
