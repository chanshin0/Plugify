# Fixture request

여러 세션에 걸쳐 기존 내부 업무 서비스를 현대화한다. capability와 실제 workflow를 먼저 발견하고, 다음 에이전트가 원 대화 없이 이어갈 수 있는 project context package와 역할 prompt를 만든다. 결과 보고에는 검증 직후 실제 디렉터리 구조를 포함한다.

정적 source inventory는 기능 존재 단서만 제공한다. 실제 사용, 업무 빈도, owner, 모든 writer, 정본, 복구 책임은 unknown이다. 따라서 architecture·물리 data model·cutover는 아직 승인할 수 없다.
