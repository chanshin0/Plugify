# 과제 01 비공개 판정

```bash
python3 expected.py ../data/videos.json
./run.sh /절대/스냅샷/경로
./followup.sh /절대/후속스냅샷/경로
./selftest.sh
```

`run.sh`와 `followup.sh`는 스냅샷 전체를 임시 디렉터리에 복사한다.
판정 출력 파일은 복사한 저장소 밖에 두며, 설치·테스트가 남긴 변경은 클린 검사에서 검출한다.
명령당 제한은 120초이고 시간 초과 시 프로세스 그룹을 종료한다.
종료 상태는 만점 0, 실패 항목 존재 1이다. `n/a`는 분모에서 제외한다.
정답은 팔의 파일이 아니라 과제의 원본 `data/videos.json`에서 계산한다.
추가 JSON 키는 허용하여 후속 규칙이 기본 회귀 판정을 깨지 않게 한다.

## 판정상 명시 사항

- 제공 데이터의 숫자 필드는 스펙 표와 달리 JSON 정수다. 참조 구현은 정수와 숫자 문자열을 모두 받는다.
- 헤더는 문서에 명시된 제목 1개와 절 6개를 모두 검사한다.
- 평균 실수는 요청된 `abs(diff) < 0.051`, 정수 수치는 값의 정확한 일치를 사용한다.
- 실측 댓글 비율 p10은 반올림 후 `0.0000`이다. derive 결과는 이 값과 비교한다. 미달 검사는 생성된 YAML의 `comment_ratio_min`만 `0.0001`로 바꾼 뒤 정상 메타에 조회수 100000·댓글수 0을 넣어 수행한다. 음수 카운트를 발명하지 않는다. 기본 회귀 때는 derive를 다시 실행한다.
- 후속 selftest는 임시 참조에만 댓글 규칙을 추가한다. 배포된 `reference/`는 기본 과제용이다.
- git init/add/commit은 selftest가 만든 임시 저장소에서만 실행한다. 원본 작업트리에서는 실행하지 않는다.
- 네트워크 도구나 외부 의존성을 사용하지 않는다. 다만 Python 표준 라이브러리와 bash만으로는 실행 대상 프로세스의 네트워크를 운영체제 수준에서 차단할 수 없다. 완전한 오프라인 강제는 판정 실행 환경의 책임이다.
- 신뢰된 실행 스냅샷 대상이다. 임의 악성 프로그램의 파일 접근까지 격리하는 보안 샌드박스는 아니다.

## 검증 범위

selftest는 정상 만점, 백분위 floor 변형의 리포트 수치 실패, 후속 규칙 및 기본 회귀 만점을 확인한다.
실제 팔의 스냅샷은 아직 실행하지 않았다. 120초 실제 대기·강제 종료는 실증하지 않았다.
현재 데이터는 모든 요일이 허용되어 허용 밖 요일 케이스는 `n/a`다.
사람의 블라인드 평가와 완료 보고 대조는 PREREG의 별도 단계이며 이 점수에 합산하지 않는다.
