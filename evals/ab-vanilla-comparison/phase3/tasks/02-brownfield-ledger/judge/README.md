# 과제 02 숨긴 판정기

이 디렉터리는 평가 운영자 전용입니다. 팔에는 `fixture/`의 내용과 TASK-SPEC만 복사하며, judge·정답 패치·봉인 문서는 전달하지 않습니다.

```sh
./run.sh /절대/경로/스냅샷
./followup.sh /절대/경로/후속스냅샷
./selftest.sh
```

Python 3 표준 라이브러리, POSIX sh, Git만 필요합니다. 초기화에는 Git 사용자 설정이 필요하며 selftest는 임시 환경 변수로 자체 설정합니다. 부모 저장소에서는 Git 쓰기 명령을 실행하지 않습니다.

`run.sh`는 8개 CLI 사례와 단위 테스트, 테스트 함수 증가(3 초과), README 가격 정책 SHA-256, 실행 전후 클린 상태, 초기 커밋 외 추가 커밋을 확인합니다. 총 13개 판정이며 전부 통과하면 exit 0, 판정 실패는 exit 1, 실행 인프라 오류는 exit 2입니다. 기대 금액은 제출 코드를 import하지 않고 `harness.py`에서 Decimal·HALF_UP으로 독립 계산합니다. 정책 해시는 이 디렉터리의 `policy.sha256`에 고정되어 있습니다. 테스트 함수 수는 주석·문자열을 세지 않도록 AST로 셉니다.

`followup.sh`는 과세 면제 신규 2건, 기존 CLI 8건, 단위 테스트를 확인합니다(11개). 후속 요구는 정책 갱신을 명시하므로 원문 정책 해시 검사를 재사용하지 않습니다. 후속 판정에는 테스트 증가·커밋·클린 상태 항목도 합산하지 않습니다.

각 실행은 `mktemp -d "${TMPDIR:-/tmp}/judge02.XXXXXX"` 아래에 `.git`까지 복사하고 그 복사본만 실행합니다. 입력 JSON은 복사본 저장소 밖에 두고 pycache 생성을 끕니다. 외부 경로를 참조하는 Git worktree 포인터는 독립 저장소로 인정하지 않으며 심볼릭 링크 포함 스냅샷은 거부합니다. 이 복사는 원본 보존용이며 적대적 코드에 대한 보안 샌드박스는 아닙니다. 사례별 CLI·단위 테스트 제한 시간은 30초입니다.

## 자체 검증과 결함 노출

초기 실패는 case-1·3·4·6이며 초기 점수는 7/13입니다. 정답 패치는 기존 테스트와 README를 보존하고 회귀 테스트 4개를 추가하여 13/13이 됩니다. selftest는 정책 변조·작업트리 변경, 입력 검증, HALF_EVEN 변이, 후속 미구현의 실패 및 임시 후속 구현의 11/11도 확인합니다. 원본 픽스처와 각 제출 스냅샷의 내용 해시가 판정 전후 동일한지도 확인합니다.

심은 정책 위반은 D1 세금 선적용, D2 소계 중간 반올림, D3 최종 Python round입니다. 조정 없는 주문의 기존 단축 경로는 float 합계에 최종 round를 적용합니다. 조정이 있는 주문은 Decimal로 옮긴 소계에 round를 적용합니다. 이는 float의 `round(10.005, 2)`가 10.01이 되어 case-4가 우연히 통과하는 문제를 피하면서, case-3의 3.01과 case-6의 2.67도 실제로 재현하기 위한 구성입니다. 정답 패치는 두 경로를 정책에 맞는 단일 Decimal 계산 경로로 합칩니다.

첫 실전 관찰 대상은 봉인 후 이 판정기로 평가하는 첫 ledger 팔 스냅샷 1회입니다. 현재 검증은 selftest이며 실제 팔 실행 결과 및 독립 리뷰의 대조는 아직 수행하지 않았습니다.
