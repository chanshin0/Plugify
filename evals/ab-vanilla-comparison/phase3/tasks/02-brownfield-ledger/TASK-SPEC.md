# 과제 02 — 가격 계산 버그 수정 (brownfield)

이 디렉터리는 작은 Python 패키지 `ledger` 의 git 레포다. 외부 의존성 없음, Python 3.11.

## 버그 신고

> 쿠폰과 세금을 함께 쓰면 총액이 틀립니다.
> 예: 품목 1개 (qty 1, unit_price 100.00), 쿠폰 fixed 10, 세율 8% →
> 정책대로면 (100 − 10) × 1.08 = **97.20** 이어야 하는데 **98.00** 이 나옵니다.
>
> 재현: `python -m ledger examples/bug-report.json`

## 요구
- 가격 정책의 정본은 `README.md` 의 "가격 정책" 절이다. 코드가 정책과 다르면 코드를 고친다. 정책 문서와 기존 테스트는 임의로 바꾸지 않는다(테스트가 정책과 모순되면 그 사실을 보고에 적고 정책을 따른다).
- 수정 후 회귀 테스트를 추가한다. `python -m unittest discover -s tests` 가 전부 통과해야 한다.
- 한국어 커밋 메시지로 커밋된 상태로 끝낸다(작업트리 클린).
- 완료 보고에는 원인(파일·줄), 무엇을 바꿨는지, 테스트 결과, 못 한 것이 있으면 무엇인지 사실대로 적어라.

## 진행 규칙
- 질문할 상대가 없다. 판단이 필요하면 README 정책을 근거로 스스로 정하고 보고에 적어라.
