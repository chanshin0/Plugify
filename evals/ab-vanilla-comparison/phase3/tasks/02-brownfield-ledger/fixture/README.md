# ledger

외부 의존성 없이 Python 3.11 이상에서 실행하는 주문 가격 계산기입니다.

## 가격 정책

1. 금액은 소수 둘째 자리 통화로 표시합니다.
2. 계산 순서는 소계(라인 합) → 쿠폰 → 세금 → 최종 반올림 한 번입니다.
3. 반올림은 최종 총액에서만 HALF_UP으로 합니다(2.675 → 2.68). 중간 반올림은 금지합니다.
4. 쿠폰은 percent(0–100) 또는 fixed(0 이상 금액)입니다. fixed가 소계를 초과하면 쿠폰 적용 후 금액을 0으로 clamp합니다.
5. 세금은 쿠폰 적용 후 금액에 적용합니다.
6. 단가는 0 이상이며 소수 넷째 자리까지 허용합니다(도매 단가). qty는 1 이상 정수입니다.

## 사용법

복사한 디렉터리에서 `./INIT.sh`로 초기 저장소를 만듭니다. Git 사용자 이름과 이메일 설정이 필요합니다.

```sh
python3 -m ledger examples/bug-report.json
python3 -m unittest discover -s tests
```

입력 형식:

```json
{"items":[{"qty":1,"unit_price":100.0}],"coupon":{"type":"fixed","value":10},"tax_rate_pct":8}
```

쿠폰은 `null`이거나 생략할 수 있습니다. 세율을 생략하면 0입니다.
세율과 쿠폰 금액은 유한한 0 이상 숫자여야 하며 불리언은 숫자로 받지 않습니다.
총액은 소수 2자리 한 줄로 stdout에 출력합니다. 입력 오류는 stderr로 안내하고 종료 코드 2를 반환합니다.

## 코드와 테스트

`ledger/pricing.py`는 입력 검증·소계·총액 계산을 담당합니다.
`ledger/__main__.py`는 JSON 파일 입출력과 오류 안내를 담당합니다.
`tests/test_pricing.py`에서 기본 주문 예제를 확인할 수 있습니다.
