# 팀 링크 모음

Python 3 표준 라이브러리만 사용하므로 설치가 필요 없습니다.

`./linkbox add https://example.com/a --title "Alpha Doc" --tag dev`
`./linkbox list [--tag dev]`, `./linkbox search Alpha`, `./linkbox remove <url>`

없는 URL 삭제는 안내와 exit 1을 반환합니다. `./test.sh`는 독립 임시 디렉터리에서 6건을 검사합니다.
명령 처리와 저장은 `linkbox.py`에 있습니다.

## 가정
- 중복 URL은 최신 입력으로 교체합니다. 같은 링크의 제목을 쉽게 갱신하기 위해서입니다.
- 태그는 입력 그대로 비교합니다. 사용자의 표기를 보존하기 위해서입니다.
- 검색은 대소문자를 구분한 제목 부분 문자열로 합니다. 작은 도구의 검색 규칙을 단순하게 유지하기 위해서입니다.
- 목록은 저장 순서이며 결과가 없으면 빈 출력과 exit 0입니다. 필터 결과를 파이프로 처리하기 위해서입니다.
- 저장은 작업 디렉터리의 links.json을 사용합니다. 별도 의존성 없이 내용을 확인하기 위해서입니다.
