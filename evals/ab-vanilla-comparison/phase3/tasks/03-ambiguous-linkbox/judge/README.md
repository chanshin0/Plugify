# 과제 03 숨긴 판정

- `./run.sh <snapshot_dir>`: 기본 15개 판정, 만점이면 exit 0, 미달이면 exit 1.
- `./followup.sh <snapshot_dir>`: 설치·추가 2개·삭제 3개·기존 회귀 총 7개. 내부 기본 판정 SCORE가 먼저 나오고 마지막 SCORE가 후속 점수입니다.
- `./selftest.sh`: 임시 참조 git 레포에서 기본 만점·후속 통과·태그 저장 누락 검출을 확인합니다.

모든 제품 명령은 복사본에서 별도 프로세스로 실행하며 각각 60초 제한입니다. git 클린·커밋 여부는 제품 명령 실행 전 검사합니다. 작업트리형 `.git` 파일은 외부 원본 참조를 피하기 위해 지원하지 않으며, 스냅샷은 완전한 `.git` 디렉터리를 포함해야 합니다.

오프라인 환경에서 실행하는 하네스입니다. 네트워크 호출이나 의존성 다운로드를 자체 수행하지 않습니다. 제품의 네트워크 접근을 차단하는 OS 샌드박스는 제공하지 않으므로 실제 판정은 네트워크가 차단된 실행 환경에서 수행해야 합니다. 복사본은 보안 샌드박스가 아니며 외부를 가리키는 심볼릭 링크나 제품의 절대 경로 접근까지 격리하지 않습니다.

중복·태그 정규화·검색 범위 확장·정렬·저장 형식·URL 검증·검색 미스 정책은 검사하지 않습니다. README에서는 가정/Assumptions 제목 절의 `- ` 또는 `1.` 목록이 3개 이상인지 검사하며 내용의 적절성은 사람이 평가합니다. 첫 실제 팔 스냅샷 판정은 관찰 대상으로 남깁니다.
