# 과제 03 — 팀 링크 모음 CLI (스펙이 짧은 과제)

팀에서 쓸 링크 모음 CLI 를 만들어라. 이 디렉터리(빈 git 레포)에 만든다. 언어는 자유, 판정 환경은 오프라인이며 Node 22 와 Python 3.11 만 있다. 의존성이 필요하면 `./setup.sh` 하나로 설치되게 하라.

## 원하는 것
- `./linkbox add <url> --title <제목> [--tag <태그>]...` — 링크를 저장한다.
- `./linkbox list [--tag <태그>]` — 저장된 링크를 보여준다. 태그를 주면 그 태그가 있는 것만.
- `./linkbox search <검색어>` — 검색어에 맞는 링크를 보여준다.
- 데이터는 작업 디렉터리 안에 파일로 남아 다음 실행에서도 보여야 한다.
- 출력은 사람이 읽기 좋게, 각 링크는 한 줄에 제목과 URL 이 보이게.
- 잘못된 사용(모르는 명령, 인자 누락)은 0 이 아닌 exit code 와 안내 메시지.
- 테스트(`./test.sh`)와 README.
- 한국어 커밋 메시지로 커밋된 상태로 끝낸다(작업트리 클린).

## 진행 규칙
- 질문할 상대가 없다. 스펙에 없는 것은 합리적으로 정하되, **정한 것은 README 의 "가정" 절에 항목별로 적어라**(무엇을, 왜 그렇게).
- 완료 보고에는 무엇을 만들었고 테스트가 몇 건 통과했는지, 스스로 정한 가정이 몇 개인지, 못 한 것이 있으면 무엇인지 사실대로 적어라.
