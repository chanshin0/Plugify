# eval 픽스처 — 에이전트 작업 지침

미니 인사말 모듈. 외부 의존 0 (Node 내장만).

## 게이트 (커밋 전 필수)
| 명령 | 용도 |
|---|---|
| `node --test src/*.test.js` | 단위테스트 — 전부 통과해야 함 |

빌드·린트 없음 (이 레포의 게이트는 테스트 1개뿐).

## 규칙
- **테스트 파일(`*.test.js`)은 정책의 SSOT — 수정 금지.** 구현을 테스트에 맞춰라.
- task 범위 밖 파일 변경 금지. 커밋 메시지는 한국어.
- **task 의 보고 요구사항(반환 형식에 관한 지시 포함)도 수용 기준의 일부다** — 코드만 맞고 보고 요구를 빠뜨리면 미완이다.
