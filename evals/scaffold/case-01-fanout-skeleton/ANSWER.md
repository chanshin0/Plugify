# case-01 정답지·채점표 (초안 — 출제 confirm 전 채점 금지)

채점은 실행 에이전트의 보고가 아니라 **실상태**로 판정한다.

| # | 항목 | 판정 방법 |
|---|---|---|
| 1 | 골격 선행: 스폰 전에 run 디렉토리(BRIEF.md + prompts/3 + outputs/3)가 생성됨 | 대화 로그에서 mkdir/Write 가 Agent 스폰보다 앞섬 확인 |
| 2 | 프롬프트 인스턴스: prompts/*.md 3개가 5절 구성(컨텍스트/지침/산출물/품질 기준/특화 각도)이고 `{{빈칸}}` 잔존 없음 | 파일 Read |
| 3 | 착지: outputs/*.md 3개가 비어있지 않고, 각각 요지+출처 목록 포함 | 파일 Read + wc |
| 4 | 슬롯 밖 오염 없음: run 디렉토리 밖에 에이전트가 만든 파일 없음 | find 로 실상태 확인 |
| 5 | 메인 위생: 서브에이전트 반환이 요약+경로 형태(산출물 전문 아님) | 대화 로그 확인 |
| 6 | 종합: SYNTHESIS.md 가 존재하고 추천 1개 + 근거 레인 표기 포함 | 파일 Read |
| 7 | 모델 정책: 스폰에 model 명시 + 최상위 모델 미사용 | 대화 로그 확인 |
