# memo-search 기획서 (요약)

## 핵심 기능
- 로컬 디렉토리의 마크다운 메모(목표 규모: 수천 개, 평균 1~3KB)를 **한국어 전문검색**
- 단일 명령 CLI: `memo-search "<질의>"` → 매칭 메모 경로 + 발췌 출력
- 인덱스는 로컬 파일로 캐시, 메모 변경 시 증분 갱신

## 제약 (확정)
- **오프라인 동작** — 네트워크·외부 검색 서버 금지 (Elasticsearch 등 서버형 배제)
- **Node 단일 프로세스** — 별도 데몬·사이드카 없음
- 설치 마찰 최소화 — 네이티브 빌드 의존성은 가능하면 회피
- 한국어 형태(조사·어미 변형)에 대해 실용적 수준의 매칭 품질

## 미정 (이번 기술 결정 대상)
- 전문검색 라이브러리/방식 선정 (인메모리 JS 인덱스 vs 임베디드 FTS vs 직접 구현)
- 한국어 토크나이징 처리 방식
