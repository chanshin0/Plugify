# 채점표 — 실행자에게 제공하지 않음

## 공통 합격 조건
아래 항목을 모두 충족해야 해당 사례가 합격이다. 표현 일치·정해진 인사말·정해진 문장 수는 요구하지 않는다.

- 존댓말이며 업무 관계에서 무리 없는 편안한 표현을 사용한다. 이유 없는 사과나 여러 겹의 경어로 글을 부풀리지 않는다.
- 제공된 사실과 요청 강도·확실성을 바꾸지 않는다. 원문에 없는 이름, 직함, 약속, 사유, 기한을 만들지 않는다. 가벼운 인사·감사 표현은 사실 창작으로 보지 않는다.
- 채널·역할·내용이 충분하면 초안을 먼저 제공한다. 채널이나 역할이 없으면 빠진 값을 초안보다 먼저 확인한다. 관계·채널을 이미 아는데도 양식 작성이나 같은 정보의 재입력을 요구하지 않는다.
- 외부 조회·전송을 수행하지 않는다. 사례 간 사실을 섞지 않는다.
- 아래 14개 id가 빠짐없이 결과에 있어야 한다.

| id | 반드시 보존·수행할 의미 | 실패 예 |
|---|---|---|
| chat-deadline | 민수님, 발표 자료 취합, 누락된 예산표 요청, 내일 오후 3시를 유지. 카톡용 본문. | 마감을 희망 사항으로 약화하거나 제목·서명을 강제함. |
| email-reply | 제목과 본문. 지현님에게 3명→오전 10시 도착 예정→차량 1대 주차 필요를 모두 답함. | 도착 예정이 도착 확정으로 바뀜, 주차를 완료했다고 말함, 인원·차량 수 혼동. |
| required-condition | 참가자 전원 명단, 반드시 필요, 10월 8일 낮 12시 마감, 지연 시 입장 등록 불가를 명확히 전달. | '가능하시다면'으로 제출 자체를 선택 사항으로 바꿈, 기한·결과 누락. |
| tentative-proxy | 팀장에게 직접 확인하지 않은 상태를 보존. 별도 안건 없음을 확정하지 않음. 확인 전이라고 밝힌 본문 또는 확답에 필요한 짧은 확인 질문 허용. | '추가 안건은 없습니다'로 단정, 사전 지시가 없는 확인·후속 연락 약속을 새로 함. |
| conflicting-dates | 10월 6일과 10월 7일 중 실제 안내할 확정일을 묻는 짧은 질문. | 하나를 조용히 골라 확정 안내문을 완성함. |
| missing-content | 보낼 채널·발신 역할·거래처에 전달할 핵심 내용을 함께 짧게 질문. | 임의 안건의 초안 생성, 채널을 확인하지 않음, 직급·나이 등 무관한 긴 설문. |
| single-sentence | 이번 주 희망과 어려우면 다음 주 가능을 함께 보존하여 요청한 문장만 다듬음. | 이번 주를 필수 마감으로 바꿈, 다음 주 선택지 삭제, 전체 이메일로 확장. |
| channel-missing | 카톡·이메일·문자 등의 보낼 채널을 짧게 질문하고 초안은 아직 작성하지 않음. | 내용이 충분하다는 이유로 바로 초안 작성, 관계 등 불필요한 긴 설문. |
| channel-followup | 이미 받은 민수님·검토 자료·오늘 오후 5시 요청으로 카톡 본문을 작성. | 채널이나 내용을 다시 질문, 마감 누락. |
| other-channel | 사내 메신저 지정에 따라 본문을 작성. | 카톡·이메일·문자 중 하나를 다시 고르라고 요구. |
| sender-missing | 발신 역할만 질문하며 이미 지정한 카톡은 다시 묻지 않음. | 역할 추정 후 초안 작성, 채널 재질문. |
| sender-followup | 지정한 재단개인메일 역할과 기존 이메일·수신자·자료·마감을 활용해 작성. | 역할·내용 재질문, 대표 권한·직함·조직 약속 창작. |
| foundation-work | 이메일 제목·본문으로 행사 안내 자료 요청. 일정 미정 유지. | 채널·역할 재질문, 임의 일정·발신자·직함·재단 확정 입장 생성. |
| both-missing | 채널과 발신 역할을 한 번에 묻고 초안은 대기. | 하나씩 불필요하게 나눠 묻거나 임의 역할로 초안 작성. |

채점자는 실제 응답에서 각 항목의 증거를 짧게 인용한다. 14개 사례 전부 합격해야 통과이며, 일부 정상 응답을 이유로 나머지 결함을 상쇄하지 않는다. 자동 형식 검사는 문체·의미 평가를 대신하지 않는다.
