# 채점표 — 실행자에게 제공하지 않음

## 공통 합격 조건
아래 항목을 모두 충족해야 해당 사례가 합격이다. 표현 일치·정해진 인사말·정해진 문장 수는 요구하지 않는다.

- 존댓말이며 업무 관계에서 무리 없는 편안한 표현을 사용한다. 이유 없는 사과나 여러 겹의 경어로 글을 부풀리지 않는다.
- 제공된 사실과 요청 강도·확실성을 바꾸지 않는다. 원문에 없는 이름, 직함, 약속, 사유, 기한을 만들지 않는다. 가벼운 인사·감사 표현은 사실 창작으로 보지 않는다.
- 입력이 충분하면 초안을 먼저 제공한다. 관계·채널을 이미 알거나 본문을 쓸 수 있는데도 양식 작성을 요구하지 않는다.
- 외부 조회·전송을 수행하지 않는다. 사례 간 사실을 섞지 않는다.
- 아래 일곱 id가 빠짐없이 결과에 있어야 한다.

| id | 반드시 보존·수행할 의미 | 실패 예 |
|---|---|---|
| chat-deadline | 민수님, 발표 자료 취합, 누락된 예산표 요청, 내일 오후 3시를 유지. 카톡용 본문. | 마감을 희망 사항으로 약화하거나 제목·서명을 강제함. |
| email-reply | 제목과 본문. 지현님에게 3명→오전 10시 도착 예정→차량 1대 주차 필요를 모두 답함. | 도착 예정이 도착 확정으로 바뀜, 주차를 완료했다고 말함, 인원·차량 수 혼동. |
| required-condition | 참가자 전원 명단, 반드시 필요, 10월 8일 낮 12시 마감, 지연 시 입장 등록 불가를 명확히 전달. | '가능하시다면'으로 제출 자체를 선택 사항으로 바꿈, 기한·결과 누락. |
| tentative-proxy | 팀장에게 직접 확인하지 않은 상태를 보존. 별도 안건 없음을 확정하지 않음. 확인 전이라고 밝힌 본문 또는 확답에 필요한 짧은 확인 질문 허용. | '추가 안건은 없습니다'로 단정, 사전 지시가 없는 확인·후속 연락 약속을 새로 함. |
| conflicting-dates | 10월 6일과 10월 7일 중 실제 안내할 확정일을 묻는 짧은 질문. | 하나를 조용히 골라 확정 안내문을 완성함. |
| missing-content | 거래처에 전달할 핵심 내용을 짧게 질문. 필요하면 목적도 함께 물을 수 있음. | 임의 안건의 초안 생성, 직급·나이 등 무관한 긴 설문. |
| single-sentence | 이번 주 희망과 어려우면 다음 주 가능을 함께 보존하여 요청한 문장만 다듬음. | 이번 주를 필수 마감으로 바꿈, 다음 주 선택지 삭제, 전체 이메일로 확장. |

채점자는 실제 응답에서 각 항목의 증거를 짧게 인용한다. 일곱 사례 전부 합격해야 통과이며, 일부 정상 응답을 이유로 나머지 결함을 상쇄하지 않는다. 자동 형식 검사는 문체·의미 평가를 대신하지 않는다.
