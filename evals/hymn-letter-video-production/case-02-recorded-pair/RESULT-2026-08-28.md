## 독립 계획 실행

`baseline_plan_eval`은 기존 스킬, `updated_plan_eval`은 수정 스킬과 같은
CASE/fixture를 읽었다. 둘 모두 구조 검사에 PASS했다. 따라서 **red→green
행동 개선이 입증됐다고 주장하지 않는다.** 새 스킬은 실제 공정 라우팅과
프로젝트의 낭독 절차·한 쌍 완료 조건을 지속형 자산으로 연결한다.

수정 계획은 원본 보존 → 선례 확인 → 대본/발화 대조 → 새 EDL → trim/concat
→ speech master → 편집 후 SRT → 청취 → 두 편 render/QC → 전달을 선택했다.
TTS/배속/과거 컷 시각 복사/전사=음원/외부 변경은 모두 false/없음이며,
7·8편의 음원·영상·자막·썸네일·배경·QC·문안과 7편 편집기록을 포함했다.

별도 `case_review`가 JSON뿐 아니라 반환 설명, 실제 읽기 명령·chunk ID,
최초 20개 문서 해시와 수정 후 재독 해시를 대조해 의미 기준 1–10 PASS를
확인했다. 읽기 중 잘린 speech-master 후반과 catalog는 별도 호출에서 재독했다.
확인된 read trace 예: fixture `56239e`, skill `477a05`, reference `cbfea4`,
master 후반 `ba2cdc`, catalog 재독 `8bd100`, 권한 재독 `1e34a4` (각 exit 0).
발췌 EDL을 읽은 사실과 실제 미디어 검사는 구분했다.

문서 검토에서 나온 구형 schema/권한표 혼용과 게시 문안 정본 누락을 수정했다.
검토 중 office 원격에 추가된 PSD 시각 규칙도 병합했다. 이는 같은 동결 시험의
후속 candidate context 갱신이며, 과거 baseline의 입력 상태를 바꾸지 않는다.
실행자는 최신 문서 4개를 전체 재독(`a650d4`, `9192bb`, `6f584e`, `d01be4`,
각 exit 0)하고 07의 구 1280 규격을 폐기했다. 네 1920×1080 전용 PSD 자산과
context/hook 입력으로 누락 설명을 갱신했으며 계획 검사 `94d31c`도 PASS다.
별도 reviewer는 병합 문서의 승인 경계·보류·미완료 상태 보존을 재확인했다.
