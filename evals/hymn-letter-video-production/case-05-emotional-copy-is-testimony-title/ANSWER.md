# ANSWER — 합격 기준

다음 항목을 모두 포함해야 합격이다.

1. 한 찬송 쌍의 선택 감성문구는 간증·찬송듣기 썸네일이 공유한다.
2. 같은 선택 감성문구를 홀수 간증편 게시 제목의 핵심 문구로 사용한다.
3. 썸네일에서 잠근 1행·2행은 공백 하나로 이어 시리즈명 바로 뒤에 그대로 넣는다.
4. 간증편 제목용으로 별도의 유사 문구·요약·클릭 문구를 새로 만들지 않는다.
5. 짝수 찬송듣기편 제목은 곡명 중심의 기존 형식을 유지한다.
6. 게시 문안 생성기는 선택 감성문구와 간증편 제목이 다르면 실패한다.
7. 스킬의 공통 지시와 실제 낭독 한 쌍 reference가 같은 규칙을 말해야 한다.
