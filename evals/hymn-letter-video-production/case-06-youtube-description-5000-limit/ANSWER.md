# ANSWER — 합격 기준

다음 항목을 모두 포함해야 합격이다.

1. YouTube 본문 제한을 영상 한 편당 최대 5,000자로 고정한다.
2. 제목을 제외한 실제 완성 설명만 계산한다.
3. 홀수 간증편은 공용 본문 전체를 계산한다.
4. 짝수 찬송듣기편은 공용 본문과 전용 제작·문의 안내를 합쳐 계산한다.
5. 합본 TXT 전체 길이나 복사용 안내 마커를 영상별 본문 길이로 대신 쓰지 않는다.
6. 둘 중 하나라도 5,000자를 넘으면 TXT 생성과 전달을 실패시킨다.
7. 게시 영수증에 최대값과 두 편의 최종 문자 수를 각각 기록한다.
8. 먼저 중복 해시태그·도입·부제목·안내를 압축하며 승인 대본을 임의로 자르지
   않는다. 그래도 넘을 때만 대본에 근거한 별도 요약 후보를 사람 검토 대상으로
   만든다.
9. 공통 SKILL과 실제 낭독 한 쌍 reference가 같은 계산 경계를 말해야 한다.
