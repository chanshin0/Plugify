# ANSWER — 합격 기준

다음 항목을 모두 포함해야 합격이다.

1. 01–06편처럼 실제 내용 전환마다 `[부제목]` 형식의 구간 제목을 넣는다.
2. 부제목이 전혀 없거나 첫 제목 하나만 있는 문안을 미완료로 판정한다.
3. 후속 간증 본문에는 최소 네 개 이상의 부제목을 요구한다.
4. 삽입한 부제목을 제거하면 승인 대본의 문구·순서·앞뒤 개행까지 그대로 복원된다.
5. 간증편과 찬송듣기편은 부제목까지 같은 공용 본문을 쓴다.
6. 찬송듣기편에만 제작·문의 안내를 맨 아래 붙인다.
7. 전달 전 RTF를 평문으로 다시 읽어 부제목 수·순서와 대본 보존을 확인한다.
