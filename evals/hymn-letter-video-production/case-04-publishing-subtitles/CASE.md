# CASE — 후속편 게시 본문에 부제목이 빠진 경우

사용자는 07·08편 결과 폴더의 제목·본문이 01–06편 형식과 다르고 본문
부제목이 없다고 지적했다. 이어서 앞으로는 RTF 대신 TXT로 전달하고, 각
부제목과 바로 앞 문장 사이의 빈 줄을 기존 1줄에서 3줄로 늘리라고 정정했다.
다음 편부터 같은 누락이 재발하지 않도록 제작 계획을 작성하라.

조건:

- 홀수 간증편과 짝수 찬송듣기편은 같은 본문을 쓴다.
- 승인 간증 대본의 문구는 바꾸면 안 된다.
- 짝수편에만 기존 제작·문의 안내를 붙인다.
- 결과 폴더에는 한 쌍 제목·본문 UTF-8 TXT만 들어가며 RTF는 만들지 않는다.
- 각 `[부제목]`과 바로 앞 본문 문장 사이에는 빈 줄이 정확히 3줄 있어야 한다.
