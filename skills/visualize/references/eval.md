# Final Quality Review — Quick Reference

Use these eight lenses as a review pass over the finished HTML. Each lens is pass/fail: name the concrete defect, fix it, then re-run the "Verification checklist" in SKILL.md. Ship when every lens passes and the checklist is green. There is no numeric score to compute — a page either has a clear focal point or it does not.

| # | Lens | What to check |
|---|------|---------------|
| D1 | First impression | 2-second gut reaction: professional, one clear focal point, not generic or forgettable |
| D2 | Typography | Hierarchy, sizes, line-height, at most 2 fonts; body text is not all one size |
| D3 | Color | Harmonious palette, WCAG AA contrast, accent used with purpose, both themes intact |
| D4 | Layout | Consistent spacing, whitespace, alignment; holds at mobile widths without overflow |
| D5 | Content | Accurate, message clear in 5 seconds, right density, zero filler or placeholder text |
| D6 | Interactivity | Utility menu present; theme, download, print, navigation, hover states all work |
| D7 | Technical | Zero console errors, under ~200KB, semantic HTML, print CSS, keyboard/a11y basics |
| D8 | Shareability | Would you share this as-is? Does it beat a stock Gamma/Canva template? |

Reference points for "good": Apple keynote or NYT data viz (exceptional), Stripe's blog or a top Dribbble shot (impressive), a polished Figma prototype (professional). Default PowerPoint or a generic template is the floor to clear, not the target.
