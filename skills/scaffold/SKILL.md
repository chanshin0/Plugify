# scaffold — 병렬 위임은 폴더부터 (틀 → 찍어내기 → 착지)

**원칙: 에이전트부터 띄우지 말고 착지 구조부터 세운다.** 서브에이전트가 받는 지시문과 내는 산출물을 대화가 아니라 파일에 정착시킨다 — 발사 전 확인, 실패 레인 재실행, 사고 조사(에이전트가 정확히 뭘 받았나), 틀 개선의 공통 기반. 구조가 병렬을 만들고, 파일이 증거를 만든다.

두 층을 구분한다:
- **틀** = `templates/` 의 역할 원형(버전관리 — 배움이 쌓이는 곳). 인스턴스가 아니라 여기가 정본.
- **run** = 실행 1회의 작업 디렉토리(틀을 복사해 빈칸을 채운 인스턴스 + 산출물). 증거로 남는 소모품.

## 적용 조건
- 적용: 일회성 지시 작업에서 서브에이전트 **2개 이상** 병렬/다단계 위임이 필요할 때.
- 비적용: 단일 에이전트 1회 위임(과공정 — 그냥 스폰) · 자체 오케스트레이션 보유 파이프라인 스킬(그 규약 우선) · trivial 질문.

## run 디렉토리 위치
- 작업이 특정 레포에 속함: `.planning/` 쓰는 지점 레포면 `<레포>/.planning/runs/<YYYY-MM-DD>-<slug>/`, 그 외 레포면 `<레포>/runs/<YYYY-MM-DD>-<slug>/`
- 소속 없는 개인·단발 작업: `~/Documents/agent-runs/<YYYY-MM-DD>-<slug>/`

## 절차

### P0 — 골격 생성 (발사 전)
```
<run>/
├── BRIEF.md            # 목표·범위·레인 목록·완료 기준 — templates/BRIEF.md 복사 후 채움
├── prompts/<레인>.md    # 레인(=에이전트 1개)마다 1파일 — templates/ 역할 틀 복사→빈칸 채움
└── outputs/<레인>.md    # 빈 슬롯을 미리 생성 (착지 자리 예약)
```
- 프롬프트 5절 구성(틀이 강제): 컨텍스트 / 지침 / 산출물 / 품질 기준 / 특화 탐색 각도.
- 맞는 역할 틀이 없으면 가장 가까운 틀을 복사해 변형하고, P4 에서 신규 틀 승격을 검토.

### P1 — 확인 게이트
- 레인 3개 이상 또는 장시간 실행이 예상되면: 트리 + 레인별 프롬프트 요지를 사용자에게 보이고 **확인 후 발사** (비싼 병렬 앞의 싼 구조 게이트).
- 그 미만: 골격 생성 후 바로 발사, 사후 보고.

### P2 — 발사
- 스폰 프롬프트는 포인터만: "지시문은 `<run>/prompts/<레인>.md` — Read 후 수행. 산출물은 `<run>/outputs/<레인>.md` 에 Write. 그 외 파일 수정 금지. 반환은 3줄 요약 + 산출물 경로만."
- 모델 명시(통상 sonnet — 전역 서브에이전트 모델 정책, 최상위 모델 지정 금지). 병렬 스폰은 한 메시지에.

### P3 — 수확
- 슬롯 실재·비어있지 않음을 **메인이 직접 확인**(ls·wc — 에이전트 보고를 믿지 않는다). 빈 슬롯 = 그 레인 실패로 취급, 프롬프트 파일 수정 후 그 레인만 재발사.
- 종합이 필요하면 `templates/synthesizer.md` 로 종합자 1개를 스폰해 **경로만** 준다(BRIEF + outputs/). 산출 = `<run>/SYNTHESIS.md`.
- 산출물이 외부인(승인자·심사자·수신자)에게 전달되는 것이면 `templates/audience-judge.md` 로 심사 레인을 추가한다 — **스폰 시 제작 맥락을 주지 않는다**(블라인드 — 맥락을 아는 심사자는 후하게 채점한다).
- **raw 산출물 전문을 메인 컨텍스트로 나르지 않는다** — 메인은 요약·경로·종합만 다룬다(lean-agent-design).

### P4 — 승격 점검 (축적 루프, run 종료 시 1회)
- 자문: "이번 인스턴스에 틀로 올릴 개선이 있나? 드러난 틀 결함이 있나? 반복돼서 틀로 추출할 새 역할이 있나?"
- 있으면 사용자에게 한 줄 제안 → y 면 plugify `skills/scaffold/templates/` 수정 + 본사 출하 규칙대로 커밋. n 이면 그대로 종료.
- **틀 결함을 run 파일 수정으로 우회하지 않는다** — 결함은 틀에 반영해야 다음 실행 전부가 좋아진다.

## 금지
- 골격 없이 2개 이상 발사 · 산출물 슬롯 밖 Write 지시 · raw 전문을 메인이 나르기
- 서브에이전트에 최상위 모델(Fable) 지정 — 전역 정책
- 틀 결함의 run-로컬 땜질 · 승격을 사용자 confirm 없이 커밋
