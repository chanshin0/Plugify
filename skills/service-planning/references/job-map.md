# Universal Job Map — 백본 매핑의 핵심 rubric

> 출처: Tony Ulwick / Strategyn, "The Customer-Centered Innovation Map" (HBR 2008), jobs-to-be-done.com.
> 원리: **모든 일(job)은 8개의 보편 단계**를 거친다. 사용자가 던지는 씨앗은 보통 그중 **1~2단계**(대개 Execute)만 담는다. 나머지 6~7단계가 "완전한 서비스가 되려면 빠진 것"의 1차 후보다.

P2(백본 매핑)에서 이 8단계를 씨앗에 돌린다. 각 단계가 **이 씨앗에 필요한가? 있으면 어떻게 처리되나? 비어있나(=빈칸)?** 를 판정한다.

---

## 8단계 + 단계별 질문

| # | 단계 | 의미 | 씨앗에 던지는 질문 | 비면(=빈칸) |
|---|---|---|---|---|
| 1 | **Define** (정의) | 목표·범위·파라미터 설정 | 사용자가 뭘 달성하려는지 스스로 아는가? 설정/구성 단계가 필요한가? | 목표 설정·온보딩·초기 구성 화면 누락 |
| 2 | **Locate** (확보) | 입력·자원·도구 찾기 | 어디서/어떻게 시작하나? 입력 데이터·대상을 어떻게 가져오나? | 진입점·탐색·검색·import 누락 |
| 3 | **Prepare** (준비) | 환경·데이터·권한 세팅 | 먼저 auth/권한/연결/데이터 준비가 필요한가? | 연동·권한·전처리 단계 누락 |
| 4 | **Confirm** (확인) | 실행 전 준비됐는지 검증 | 미리보기·요약·확인 단계가 있나? | 프리뷰·검토·"정말 할까요?" 누락 |
| 5 | **Execute** (실행) | 핵심 동작 — **보통 씨앗 위치** | 주 동작은? 변형·분기가 있나? | (대개 여기 있음) 변형 처리 누락 |
| 6 | **Monitor** (관찰) | 진행·상태·결과 확인 | 진행률·실시간 상태·알림이 보이나? 완료를 추적하나? | 진행표시·상태·알림 누락 |
| 7 | **Modify** (수정) | 틀리면 조정 | undo/편집/재시도/중단 가능한가? 에러 상태는? | 편집·취소·재시도·에러복구 누락 |
| 8 | **Conclude** (종료) | 마무리·보관·내보내기·이탈 | 완료 확인? export/저장/보관/삭제? 다음 핸드오프? | 완료처리·export·보관·오프보딩 누락 |

---

## 적용 규칙 (결정성)

1. **씨앗 위치 먼저 표시** — 8단계 중 씨앗이 어디 있는지 markdown으로 박는다 (보통 Execute, 화면 씨앗은 Execute~Monitor).
2. **앞뒤로 확장** — 씨앗 단계 *이전*(Define~Prepare)과 *이후*(Monitor~Conclude)를 각각 채운다. before/during/after.
3. **비어있으면 빈칸으로 등록** — 단계가 이 씨앗에 필요한데 씨앗이 안 담고 있으면 → completeness-rubric 카테고리 1(여정 단계)의 빈칸으로 넘긴다.
4. **불필요한 단계는 명시적으로 제외** — 청중 스코프/도메인상 그 단계가 없으면 "(N/A: 이유)"로 표시. 추측으로 채우지 않는다.

## 워크드 예시 — "회의 녹음 → 할 일 자동 추출" (기능 씨앗)

| 단계 | 이 씨앗에서 | 빈칸? |
|---|---|---|
| Define | 어떤 회의를 대상으로? 자동 vs 수동 트리거? | ⚠ 트리거 정의 누락 |
| Locate | 녹음 파일은 어디(Zoom 클라우드/로컬)? | ⚠ 소스 연결 누락 |
| Prepare | 전사(transcription) 파이프라인 | ⚠ 전사 단계 암묵 |
| Confirm | 추출 전 미리보기? | ⚠ 누락 |
| **Execute** | **할 일 자동 추출 ← 씨앗** | (있음) |
| Monitor | 추출 진행률·신뢰도 표시 | ⚠ 누락 |
| Modify | 추출된 목록 편집/삭제/재할당 | ⚠ 누락 |
| Conclude | task 시스템(Jira/Notion)으로 export, 녹음 보관 | ⚠ 핸드오프 누락 |

→ 씨앗은 Execute 1개만 담았는데, 완전한 서비스가 되려면 7개 단계의 빈칸을 채워야 함이 한눈에 드러난다.
