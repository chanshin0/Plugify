# handoff — 세션 이어가기 준비 (컨텍스트 정리)

**완료 기준 하나: "새 세션이 이 대화 없이 이어갈 수 있는가."** 대화에만 존재하는 정보를 0으로 만든다. 정본에 이미 있는 내용은 재복사하지 않는다(중복 금지 — 포인터만). 2026-07-07 dryforge→Phase D 세션의 마무리 절차를 규약화한 것.

## P1 — 산재 상태 수집
- 이번 세션이 만진 레포 각각: `git status --porcelain`(더티?) + `git log origin/<branch>..HEAD --oneline`(미푸시 로컬 커밋?) — **에이전트/워크플로우 보고가 아니라 git 직접**(커밋 실재는 git 이 SSOT).
- 진행 중 백그라운드 작업(워크플로우·에이전트·장기 명령): 완료 대기 or 명시적 중단 — 어중간하게 버려두지 않는다.
- 대화-전용 정보 스캔(내릴 후보): 사용자가 확정한 결정, 리뷰 advisory 와 그 처분, 환경 발견(함정·설치·수정), 미완 항목과 그 이유, 세션 중 배운 비자명 사실.

## P2 — 정본으로 내리기 (위치 규약)
| 종류 | 정본 위치 |
|---|---|
| 프로젝트 진행 상태·다음 task·사람 게이트 | 그 레포의 이어가기 앵커(`.planning/STATE.md` 등 — 레포 규약 따름) |
| 공정(시스템) 변화·첫 실전 관찰 실증 | plugify `SYSTEM.md` — 실증 주석은 달되 **첫 실전 관찰 닫기(줄 제거)=사람** |
| 레포 종속 환경 함정·비자명 사실 | 지점 `.planning/notes.md` (규약 정본 = live-verify SKILL §지점 노트 — 기록 기준 3종·양방향 정정) |
| 장비 종속 사실·프로젝트 진입 포인터 | 메모리(`~/.claude/projects/.../memory/`) — **stale 서술은 정정**하고 MEMORY.md 인덱스 라인도 갱신 |
| 사용자 선호·작업 방식 피드백 | 전역 `~/.claude/CLAUDE.md` + 메모리(type: feedback) |
- 커밋은 각 레포 규율대로: 본사=커밋(출시), 지점=로컬 커밋까지(push=사람). `--no-verify`/`--force` 금지. 문서-only 정리는 trivial 우회로(직접 편집+커밋).

## P3 — 이어가기 요약 출력 (새 세션 첫 화면용, 사람의 언어로)
1. **저장 내역**: 무엇을 어디에 내렸나 — 레포별 커밋 해시 포함, 트리 클린 여부 명시.
2. **사람 결정 대기 목록**: push/merge·출제 confirm·첫 실전 관찰 닫기 등 — 각 항목이 "무엇을 하면 닫히는지"까지.
3. **재개 진입점**: 새 세션에서 어떤 파일부터 읽고 어떤 말로 시작하면 되는지 한 줄.
4. 이번 세션에서 남겨둘 만한 아이디어·배움이 자동으로 추려져 대기 중이면(second_brain 레포 수집 큐), 훑어보고 저장할지 고르자는 제안 한 줄 — 시작 문구는 "브레인 후보 검토"(정본: second_brain CLAUDE §2.1).
5. (해당 시) 세션 재시작의 부수 효과 — 예: 이번에 바뀐 에이전트 정의는 재시작 후에야 레지스트리에 반영됨.

## 금지
- 정본 내용의 요약 재복사(포인터로 대체) · 미완을 완료로 기록 · 확인 안 한 상태를 "클린"으로 보고 · 첫 실전 관찰 줄 제거(사람 몫) · 새 결정 발명(내리는 것만 — 설계 변경은 이 스킬 범위 밖).
