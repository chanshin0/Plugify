# 심사자 관점 최종 QA

최종 PPTX를 내보낸 뒤 모든 슬라이드 PNG를 실제 크기로 열어 아래 순서로 확인한다. 하나라도 실패하면 해당 슬라이드만 고치는 데 그치지 말고, 변경 때문에 앞뒤 슬라이드의 간격·위계가 달라졌는지도 다시 본다.

## 1. 5초 판독

- 제목만 읽어도 이 슬라이드가 증명하는 공적을 알 수 있는가?
- 사진을 보고 실제 활동의 대상·방식·현장을 식별할 수 있는가?
- 수치는 무엇의 수치인지 같은 시선 범위에서 알 수 있는가?
- 검색·제작·내부 보관 과정에 관한 문구가 남아 있지 않은가?

## 2. 사진 캡션

- 모든 자료 사진 또는 논리적 사진군 가까이에 한 줄 정보가 있는가?
- 캡션이 `언제·무엇·어디서` 중 심사에 필요한 정보를 제공하는가?
- `재단 보유 사진`, `NAS`, `화면 확인`처럼 증빙 자체의 의미와 무관한 표현이 없는가?
- 날짜가 캡션과 본문에 이중 표기되지 않았는가?
- 캡션이 추가되면서 제목·설명·하단 상자와의 간격이 눌리지 않았는가?

## 3. 수치와 점수

- 모든 숫자에 대상과 단위가 붙어 있는가?
- 같은 수준의 수치가 같은 글자 크기·색·기준선으로 보이는가?
- 점수·평점이 있다면 소수점과 항목 구분자가 헷갈리지 않는가?
- 한 항목만 불필요하게 두 줄로 꺾이지 않았는가?
- 요약 슬라이드에 숫자가 있다면 위에 묶음의 의미가 있고, 아래에 해석이나 결론이 있는가?

## 4. 동등성·정렬·레이어

- 동등한 사례 두 개의 사진, 캡션, 제목, 설명이 같은 그리드를 쓰는가?
- 목록 텍스트가 박스 안에서 시각적으로 세로 중앙에 있는가?
- 사진·캡션·본문·하단 박스가 겹치거나 가리지 않는가?
- 페이지 번호, 출처 밴드, 하단 문구가 안전 여백 안에 있는가?

## 5. 기계 검증과 산출물

- Presentations 스킬의 오버플로 검사와 전 슬라이드 렌더를 통과했는가?
- PPTX XML의 typeface가 선택한 서체로 일관되는가?
- 글꼴 포함 여부 또는 수신자 환경의 대체 글꼴 위험을 확인했는가?
- 공개 웹 출처는 발표자 노트 `[Sources]`에 남고, NAS·내부 문서의 정확한 경로와 비공개 식별자는 외부 PPTX가 아닌 로컬 검사 sidecar에 분리됐는가?
- 각 날짜·장소·수치·캡션을 출처 본문과 다시 대조했는가?
- 외부 제출에 사용할 사진의 권리와 미성년자·명찰·연락처 등 개인정보 노출을 확인했는가?
- 공고문·제출 안내가 있다면 슬라이드 수, 파일 크기, 화면비, 필수 순서, 형식과 파일명이 맞는가?
- 최종본은 새 버전으로 저장되었고, 사용자 확정 전 이전 버전이 보존되어 있는가?
- 확정 후 정리 시 같은 파일명 계보의 이전 PPTX와 검사 sidecar만 후보로 확인했고, 확정본·다른 덱·원본 자료를 제외했는가?
